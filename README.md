# Yatra Partner

A responsive travel agency landing page developed as a college web development assignment. The project focuses on clean UI/UX design, responsive layouts, and the practical application of frontend technologies.

##  Assignment Objectives
- Demonstrate proficiency in HTML5 and CSS3.
- Implement a mobile-first responsive design using Bootstrap 5.
- Apply CSS animations and transitions for improved user interaction.
- Organize project assets (images and stylesheets) in a professional directory structure.

##  Key Features
- **Responsive Navigation**: Features a sticky header with a functional mobile hamburger menu.
- **Dynamic Hero Section**: Includes a visually engaging background with CSS-based fade-in animations.
- **Destination Showcase**: A grid-based layout displaying travel spots with hover-scale effects on images.
- **About & Contact Modules**: Structured pages providing company mission statements and a stylized contact form.

##  Tech Stack
- **HTML5**: Semantic structure for all pages.
- **CSS3**: Custom styling, Google Fonts (Montserrat) integration, and layout management.
- **Bootstrap 5**: Grid system and utility classes for responsiveness.
- **Vanilla JavaScript**: Lightweight script for navigation toggling.
- **Font Awesome**: Iconography for service highlights.

##  Project Structure
- `index.html`: Main landing page.
- `aboutus.html`: Company information and values.
- `contactus.html`: Contact details and inquiry form.
- `style.css`: All custom styles and animations.
- `/docs`: Project assets including logos and destination photography.
